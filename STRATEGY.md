## Daily Rules (REVISED Jun 2026 — sustainable version)

The old "minimum 2/day" rule is what made this quit-prone. A quota you miss feels like
failure, and failure makes you stop. New rule is built for showing up *forever*, not sprinting.

1. **ONE problem a day.** That's the whole commitment. On a bad/foggy day, one *easy* one
   still counts — the point is the habit, not the difficulty. On a good day, do five.
2. **Log it in `solved.md`** — the pattern it taught, and "if I saw it cold again" trigger.
   That file is the visible artifact. No streak counter (NO-TRACKERS / Principle #0).
3. **Don't spend more than 45 min** on a problem — take a hint, then the solution. Hints
   teach the *trigger*; they're not cheating.
4. **After a solution, recode it yourself** without looking. Recognition > memorization.
5. Spaced repetition happens naturally — when a pattern row in solved.md is still 🟡, redo one.

**Why "behind" is mostly fiction (Jun 2026):** ~75 already done, pattern plan exists, C++ set.
12 months × 1/day ≈ 365 problems. People crack FAANG on 300. This is a reps gate, not a talent
gate — and showing up daily is a thing you can clearly do (you ship in 24-hr sprints, you rallied
80 people). The real target is the post-3rd-year internship (~mid-2027). On time, with runway.
