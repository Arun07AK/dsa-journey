The whole pattern on one card

Every sliding-window problem is one of these five. The interview skill is recognizing which from the prompt:

If the prompt asks…It's this variationThe move
"…over any k consecutive…"1 · Fixed windowslide a width-k window; O(1) add-right / drop-left
"longest … with sum ≤ k"2 · Sum constraintexpand R; shrink L while sum > k; record length
"longest … with at most N of x"3 · Count constraintexpand R; shrink L while count > N; record length
"longest … no repeats"4 · Not-repeatedexpand R; jump L past the last duplicate; record length
"how many subarrays with product < k"5 · Count subarraysexpand R; shrink L until valid; res += r-l+1
  • Shared spine: R almost always marches forward; L only moves to restore the constraint. The window never resets to the start — that's why it's O(n), not O(n²).
  • Fixed vs variable: variation 1 keeps a constant width; 2–5 let the width breathe.
  • Longest vs count: 2–4 track a best length; 5 accumulates — a legal window of width w adds exactly w new subarrays.
